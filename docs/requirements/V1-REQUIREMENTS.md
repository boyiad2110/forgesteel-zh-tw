# Forge Steel 繁體中文版 V1 需求

- 文件狀態：正式需求草案
- 原版基準：`267ca1a10dcab32a700089fc65dd212dc81f880a`
- 最終決策者：專案負責人

## 1. 專案目標

建立 Forge Steel 的獨立繁體中文版，讓玩家能用繁體中文完整建立與使用官方 1～3 級角色，降低漏選項的情況，並減少 GM 人工檢查角色的負擔。

V1 完成後可公開提供給台灣 Draw Steel 玩家使用。

## 2. 核心原則

1. 中文只改變顯示，不改變原版資料與規則。
2. 英文原始資料是唯一基準。
3. 不修改原版的計算、ID、enum、引用關係或存檔格式。
4. 除中英文切換外，不新增或重新設計原版功能。
5. 除明確排除的內容外，原版功能與操作流程應維持不變。
6. 專案負責人是所有中文譯文的唯一定稿者。

## 3. V1 範圍

### 3.1 官方內容

V1 納入凍結基準中的下列正式官方來源：

- Core
- Orden
- Beastheart
- Summoner

V1 必須涵蓋建立與使用 1～3 級角色所需的所有玩家內容，包括角色選項、能力、裝備、說明文字與玩家介面。

### 3.2 玩家功能

玩家必須能依照原版流程：

- 建立完整的 1～3 級角色
- 升級至 2 級與 3 級
- 儲存並重新開啟角色
- 查看角色表
- 使用原版既有的角色管理功能
- 在繁中與英文之間切換

### 3.3 GM 功能

- 原版 GM 功能保留。
- V1 尚未翻譯的 GM 功能可維持英文。
- GM 功能尚未完整中文化，不阻擋 V1 發布。

## 4. 排除範圍

中文版不納入：

- Community 內容
- Third Party 內容
- Homebrew／自製內容與功能
- Patreon 預覽內容
- Playtest、測試版或其他未正式發布內容

上述內容不得載入、顯示或出現在選單、搜尋、隨機產生與角色建立流程中；切換到英文後也不得重新出現。

既有瀏覽器中的 Homebrew 資料不得自動刪除，中文版只是不讀取、不顯示、不修改。

## 5. 中英文切換

- 預設顯示繁體中文。
- 提供一鍵切換繁中／英文。
- 記住使用者上次選擇。
- 切換時不得遺失角色資料、未儲存狀態或目前頁面狀態。
- 切換後角色數值、選項與存檔內容必須完全一致。
- 中文模式下，尚未翻譯的 GM 內容可繼續顯示英文。
- 英文模式只顯示中文版允許的官方內容。

## 6. 翻譯規則

1. AI 可提取原文、提出建議並標記漏翻、錯字、格式與術語問題。
2. AI 不得自行覆寫或修改正式中文譯文。
3. 所有中文修改都必須由專案負責人確認。
4. `develop` 可暫時保留英文。
5. V1 正式版不得出現未翻譯的 1～3 級玩家介面或官方玩家內容。
6. 玩家自行輸入的名稱與文字保持原樣，不自動翻譯。

翻譯資料格式待 codebase 與中文化架構盤點後決定；應支援唯一識別碼、英文原文、中文譯文、狀態、備註與原文更新檢查。

## 7. 相容性與版面

- 中文版沿用原版存檔格式。
- 原版角色資料應能在中文版正常開啟。
- 中文版角色資料應盡量可由原版讀取。
- 中文不得造成按鈕消失、文字重疊、內容截斷、無法捲動或主要操作失效。
- 裝置、瀏覽器與畫面尺寸支援範圍跟隨原版，不另外擴充。

## 8. 測試與發布條件

### 必測

- 每個官方職業至少建立 1 名角色，並由 1 級升至 2 級。
- 完整檢查所有 1～2 級玩家內容。
- 抽樣檢查 3 級內容與升級流程。
- 測試儲存、重新開啟及原版存檔相容性。
- 測試繁中切換英文，再切回繁中。
- 確認切換前後資料與數值不變。
- 確認所有排除內容不會載入或顯示。
- 由專案負責人與團員進行封閉 Beta。
- 通過 lint、TypeScript、自動測試、production build 與翻譯缺漏檢查。

### 發布權限

- AI Agent 不得自行發布 Beta 或正式版本。
- 只有專案負責人可以批准 V1 正式發布。
- 玩家內容翻譯未完成、最低測試未通過或授權未確認時，不得公開發布。

## 9. 版本、部署與限制

- V1 固定使用原版基準 `267ca1a10dcab32a700089fc65dd212dc81f880a`。
- V1 開發期間不持續同步原版新功能或新內容。
- 嚴重錯誤與安全修正可例外評估，由專案負責人決定。
- 部署與維護預算為 0，只考慮免費服務。
- 接受平台提供的免費網址。
- 公開前必須確認 GPL 義務、Draw Steel 內容授權、法律聲明與來源註記。
- 目前已知的依賴套件安全警告需在公開前完成風險評估。

## 10. 可延後至 V1.1

下列項目不列入 V1 必要發布條件：

- PDF 匯出的完整中文排版
- 圖片匯出的完整中文排版
- 中文字型與列印排版最佳化

原版既有功能不應刻意刪除；若中文輸出有問題，V1 應列為已知限制。

## 11. V1 完成標準

V1 必須同時符合：

1. 玩家可用繁體中文完整建立與使用官方 1～3 級角色。
2. 所有 V1 玩家內容與介面均已完成中文定稿。
3. 中英文切換不影響角色資料與計算。
4. 原版功能與流程未因中文化而改變。
5. 排除內容不會載入或顯示。
6. 最低測試與自動檢查全部通過。
7. 授權與發布文字已確認。
8. 專案負責人批准正式發布。

- 免費部署平台
