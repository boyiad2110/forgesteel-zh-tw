## 本批範圍

只投射上游已計算的整數，不在中文顯示層重新計算。未計算文字仍顯示核准的靜態中文；英文計算結果若有其他差異，保留整段英文。

| 族裔／特性 | 核准中文動態格式 | 驗收重點 |
|---|---|---|
| 魔鬼／尖刺尾巴 | `{value} 點傷害` | 以最高屬性值呈現額外傷害 |
| 魔鬼／飛翼 | `{value} 輪` | 以力量呈現滯空輪數，保留「至少 1 輪」 |
| 波德人／腐朽免疫 | `腐朽免疫 {value} + 2` | 保留上游的 `1 + 2`／`5 + 2` 算式，不代算 |
| 還魂屍／枯而不朽 | `{value} 點體力` | 恢復值使用角色上游數值 |
| 還魂屍／復仇符印 | `{value} 個符印` | 描述全文保留，僅投射符印數量 |
| 時空獵手／心靈傷痕 | `心靈免疫 {value}` | 以角色等級呈現 |
| 龍騎士／龍人守衛 | `讓該次打擊減少 {value} 點傷害` | 使用文字效果段落的核准網站適配 |

數字與中文相鄰處由顯示層加入半形空格。書面英文開關仍顯示英文。龍人守衛的摘要標語與文字效果段落是不同用途；本批只接上段落的等級投射。

## 人工驗收位置

在建立或編輯英雄時，選擇相應族裔與特性，查看特性卡片的描述：

1. 魔鬼：尖刺尾巴、飛翼。
2. 波德人：腐朽免疫。
3. 還魂屍：枯而不朽、復仇符印。
4. 時空獵手：心靈傷痕。
5. 龍騎士：龍人守衛的文字效果段落。

有角色資料時，確認數字依該角色的屬性、等級或復元值顯示，中文句型如表格；關閉計算或尚未選角時，確認靜態中文顯示。若上游描述包含額外改寫，確認系統保留完整英文。
