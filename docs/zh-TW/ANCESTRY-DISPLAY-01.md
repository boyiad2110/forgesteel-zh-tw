# 族裔顯示補接 01

## 本批狀態

實作已完成，正分項進行 Marc 人工驗收。本批只接既有 APPROVED mapping／UI，不新增或修改譯文、mapping、快照或 Sheet 狀態；文化、生涯、專長與無核准網站適配的族裔段落均未納入。

工作分支：`codex/ancestry-approved-display-fixes`。

## 修補範圍

1. Classic／Reference 的族裔特性現在只在官方來源與特性名稱、型別、資料結構吻合時接入名稱與描述對照。Classic 對描述所做的顯示清理不會改動遊戲資料；中文解析仍核對實際顯示原文。改名、自訂或結構不同的特性不會因 ID 相同而直接中文化。
2. Classic 族裔招式卡對已核准的文字效果，會將自動加上的 `Effect:` 標籤獨立顯示，使效果段落能吻合原核准文字。只對已映射段落拆標籤；未核准／無 mapping 的段落維持原顯示。
3. 還魂屍「昔日人生」的族裔下拉選單與已選摘要，官方族裔簡介接入既有對照；自訂族裔仍保留原文。
4. 前世特性候選清單在官方特性吻合時接入既有名稱、描述對照；空清單提示接入既有核准 UI。Homebrew／自訂候選保留原值。
5. 族裔招式的 Classic 特性列與招式卡使用既有核准 UI 對照顯示動作類型；僅對來源 ID、名稱與動作類型符合官方族裔招式的內容生效。
6. 族裔詳情在套用已有計算綁定的文字前先保留上游計算結果，再由核准模板投射中文；未知／未綁定的計算文字仍以完整計算後英文顯示。

## 全族裔 Classic 盤點補記（2026-10-18）

- 依 12 個內建族裔資料遞迴盤點 139 個唯一特性節點，涵蓋巢狀選項與複合特性。新增 `src/l10n/ancestry-classic.test.tsx`，以 Classic `FeatureComponent` 逐節點確認所有可直接顯示且已有 mapping 的名稱與靜態描述；族裔招式本體名稱及詳情多段落另有 `lookup.test.ts` 回歸覆蓋。此為元件靜態渲染檢查，不等同所有頁面與列印版面人工驗收。
- 盤點發現「Main Action」已有核准 UI，卻未接在族裔招式 Classic 特性列及招式卡；本次已接入，並保護自訂招式名稱／動作類型。此項仍待 Marc 在 Classic 表格人工確認。
- 同一全域掃描也確認詳情頁的 Doomsight 計算顯示有漏接；FeaturePanel 原先為了對照核准文字而跳過復元值換算。本次已改為使用計算後英文交由既有核准綁定投射，13／16 等實際數值由上游提供，不修改角色資料或計算規則。
- 還魂屍「枯而不朽」與「復仇符印」的文字在 Classic 表格會先由上游套用復元值／等級計算；計算後原文不同於核准網站原文，目前沒有對應的 `calculation-bindings.json` 核准句型。依動態文字規則，此時整段保留計算後英文；不得略去計算值來套用靜態中文，也不得自行新增綁定。前述「復仇符印」的建角候選預覽通過，不能推論 Classic 表格計算後的內容也通過。
- 結構化傷害修正的 `Damage Modifier`、`Immunity`／`Weakness` 與傷害類型，以及族裔 Power Roll 的 tier 文字仍有英文；目前 Classic 生成欄位沒有與其完整格式及用途相符的核准 UI／網站適配。本批不把此類英文算作翻譯完成。
- 全族裔尚有網站適配缺口：7 段招式短描述、8 段文字效果、2 段 Multiple 外層介紹；族裔招式的關鍵字、射程、目標、觸發句與動態 Power Roll tiers 也未整批完成。詳見上一節「排除項目」及 [四類盤點](FOUR-CATEGORIES-AUDIT-2026-10-18.md) B1／B2；需另做預覽核准批次。
